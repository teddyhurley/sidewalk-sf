# Public geographic assets

`sf-blocks-2020.json` contains reviewed San Francisco Census 2020 block geometry from DataSF `e2st-aufe`, clipped to the shoreline. It contains boundaries, not police reports, personal route history, or credentials. Its provenance and integrity manifest are embedded in the file; validation results are in `docs/block-boundary-validation.json`.

`sf-facilities-reviewed.json` is the separately reviewed public facility directory. Entries carry source links, classification notes and review deadlines. Facility types do not imply danger or affect route recommendations.
